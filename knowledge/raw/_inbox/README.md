# _inbox — entrada

Jogue aqui o material que ainda nao foi classificado: PDF, markdown, texto colado, link.
Sem organizar.

Depois, com a sessao aberta na raiz do vault:

```
/ingest
```

O comando le o que esta aqui, classifica por tipo, move para a pasta certa em `raw/` e escreve o
fichamento correspondente em `wiki/{area}/`.

O inbox fica vazio de novo. Se algo sobrar, e porque nao foi possivel classificar — o agente diz
o que faltou.
